> Например: «Система обнаружения мошеннических транзакций, которая ловит 78% фрода
> при 1% ложных блокировок — на 23 п.п. больше, чем правила-бейзлайн».

**Демо:** [Hugging Face Space](https://huggingface.co/spaces/USER/SPACE) ·
**Статья:** [Хабр](https://habr.com/)

## Проблема

Кто страдает от проблемы, сколько это стоит бизнесу, почему простое решение не работает.
2–4 предложения, без воды.

## Данные

- Источник и лицензия датасета, ссылка.
- Размер, период, доля положительного класса.
- Главные особенности и ловушки (дисбаланс, пропуски, утечки, сдвиг во времени).

## Подход

Кратко: как устроено решение и почему выбраны именно такие методы.
Схема архитектуры (можно Mermaid-диаграммой прямо в README).

## Как это работало бы в продакшене

- Нагрузка и требования к задержке, как масштабировать.
- Мониторинг: какие метрики и дрифт отслеживать.

## Запуск

```bash
git clone https://github.com/KiraPankov/ml-project-template.git && cd ml-project-template
make install        # зависимости + pre-commit
make train          # обучение, модель в models/, метрики в reports/
make test           # тесты
make serve          # API на http://localhost:8000/docs
```

Через Docker:

```bash
make train && make docker-build && make docker-run
curl -X POST localhost:8000/predict -H "Content-Type: application/json" \
  -d '{"records": [{"f0": 0.1, "f1": 0.2, "f2": 0.3, "f3": 0.4, "f4": 0.5, "f5": 0.6, "f6": 0.7, "f7": 0.8, "segment": "a"}]}'
```

## Структура

```
├── configs/            # параметры экспериментов (YAML)
├── data/               # данные (не хранятся в git)
├── models/             # обученные модели (не хранятся в git)
├── notebooks/          # EDA и исследования
├── reports/            # метрики и графики
├── src/mlproject/
│   ├── config.py       # загрузка конфига
│   ├── data.py         # загрузка и разбиение данных
│   ├── features.py     # предобработка
│   ├── models.py       # реестр моделей
│   ├── evaluate.py     # метрики
│   ├── train.py        # пайплайн обучения
│   ├── predict.py      # инференс
│   └── api.py          # FastAPI-сервис
└── tests/
```
